💻 代码替换步骤

步骤4：添加网站图标

在所有HTML文件（index.html, culture.html, resources.html, about.html）的 <head> 标签中添加：

<link rel="icon" type="image/x-icon" href="images/logo/favicon.ico">
步骤5：替换导航栏Logo

在所有HTML文件中找到这段代码：

<a href="index.html" class="logo">
    <span class="logo-icon">🎓</span>
    <span class="logo-text">AI英语学习</span>
</a>

替换为：

<a href="index.html" class="logo">
    <img src="images/logo/logo-sm.png" alt="Logo" class="logo-icon" style="width: 36px; height: 36px; object-fit: contain;">
    <span class="logo-text">AI英语学习</span>
</a>
✅ 完成后效果：导航栏将显示你的真实Logo图片，浏览器标签页也会显示你的图标

🔧 测试Logo是否正确

在浏览器控制台（F12）中运行以下代码测试Logo文件是否存在：

// 测试Logo文件
const logoFiles = ['logo.png', 'logo-sm.png', 'favicon.ico'];
logoFiles.forEach(file => {
    fetch(`images/logo/${file}`)
        .then(res => console.log(`✅ ${file}: ${res.ok ? '存在' : '不存在'}`))
        .catch(err => console.log(`❌ ${file}: 不存在`));
});

❓ 常见问题

Q: Logo不显示怎么办？
  • 检查文件路径是否正确：images/logo/logo-sm.png
  • 检查文件名是否完全一致（注意大小写）
  • 按 Ctrl+F5 强制刷新浏览器缓存
  • 打开浏览器开发者工具（F12）查看是否有404错误
Q: Logo太大或太小怎么办？

修改 style 中的尺寸：

style="width: 36px; height: 36px;"

根据需要调整数值（推荐 32-48px）

Q: favicon不显示怎么办？
  • 浏览器会缓存favicon，需要清除缓存
  • 在新的隐私窗口中打开网站测试
  • 部署到服务器后通常会正常显示
